Class Exercise: Digital vs Organic Intelligence

John Day led a foundational exercise comparing digital (AI) intelligence with organic (human) intelligence. This exercise became the centerpiece of the session's pedagogical approach, establishing the conceptual foundation for all subsequent work with Claude and other AI tools.

🤖 Digital Intelligence (AI)
  • Token-based processing: ~100,000 tokens represent English language
  • Statistical prediction: identifies frequency of token patterns
  • Probabilistic selection: randomly picks from top 10 likely tokens
  • Computational intensity: ~100 trillion operations per prompt
  • Pattern-matching: simultaneous access to entire language corpus
  • Deterministic: follows mathematical/statistical rules
🧠 Organic Intelligence (Human)
  • Experience-based: draws from lived experiences and memories
  • Contextual understanding: grasps nuance, metaphor, cultural meaning
  • Intentional selection: conscious choice based on purpose
  • Limited scope: shaped by personal experience and perspective
  • Semantic depth: understands multiple meanings and implications
  • Creative capacity: generates original ideas beyond pattern matching

The Three Levels of Word Meaning: A Teaching Framework

LEVEL 1: DEFINITION

Dictionary definition and basic meaning. "Dog" = canine animal.

LEVEL 2: CONTEXT

Contextual transformation and idiom. "Sly dog" = a clever person acting questionably.

LEVEL 3: PATTERN

Vast corpus patterns: millions of sentences showing all usage contexts.

Key Insight: AI reads all three levels simultaneously, accessing pattern data no individual human could catalog. This simultaneous access is AI's core advantage.

⚠️ KEY LIMITATION: HALLUCINATIONS

Because AI generates tokens one at a time based on statistical likelihood—randomly selecting from the top ten most probable options—it can produce what are called "hallucinations." These are nonsensical or fabricated responses that arise from odd runs of the probabilistic selection process. This represents a fundamental limitation of token-based generation.

The Solution: RAG (Retrieval Augmented Generation) employs word syntax and semantic relationships to reduce searchable data by over ten million times. This approach parallels how legal researchers use Boolean keywords to narrow search results to manageable subsets.

Exercise Methodology: From Prompt to Visualization

The session's primary learning exercise involved a structured workflow using Claude to respond to complex prompts, then visualizing the results for enhanced comprehension. This methodology transforms dense text output into organized, accessible knowledge products.

The Four-Step Workflow

  1. Write the Prompt: Use external writing tool (Google Docs, Word) to craft coherent, multi-sentence prompt incorporating personal knowledge. This transcription step ensures clarity before sending to AI.
  2. Paste into Claude: Copy prompt into Claude interface and execute. Receive comprehensive text response covering the topic.
  3. Request Visualization: Use the command: "Create an HTML artifact, not an inline widget, that visualizes and organizes the last response in this conversation."
  4. Review & Refine: Examine the resulting web page. Edit the visualization within Claude if needed. Download or share the resulting HTML file.
✅ Why Visualization Matters
  • Reduces cognitive load of dense text
  • Adds hierarchy and clear organization
  • Uses color and position for emphasis
  • Enables easier comparison of ideas
  • Facilitates sharing and presentation
  • Transforms raw output into knowledge product
💡 Key Pedagogical Points
  • Write prompts outside AI tool (Google Docs)
  • Include personal knowledge and context
  • AI can correct typos and small errors
  • Visualization is optional but powerful
  • Technique works for ChatGPT, Gemini too
  • Advanced: "Writing Coach" for iterations

📌 Technical Details: Understanding "Visualization" in AI Context

HTML Artifact refers to a web page generated by Claude containing organized, styled information. This is distinct from:

  • Inline widgets (embedded directly within chat)
  • Plain text responses (unstyled output)
  • Downloaded versus viewed-only files

The HTML artifact can be edited further within Claude, downloaded to local storage, hosted on GitHub Pages, or shared across platforms. This flexibility makes it ideal for creating reusable resources and documentation.
