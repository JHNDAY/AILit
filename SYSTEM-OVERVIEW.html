Common Pitfalls to Avoid

  • Don't give both options to beginners. Pick one (recommend web-based). Too many choices = confusion.
  • Don't assume they'll read guides. Make the interface so simple it's self-explanatory.
  • Don't forget to test. Run the web runner with real volunteer data before deploying.
  • Don't rely on error messages. Add friendly, helpful log output to guide users.
