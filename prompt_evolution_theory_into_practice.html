An Anatomy of a Prompt for:
Theory Into Practice

Four passes, one narrative — watching a visualization brief become buildable.

This traces the actual prompt iterations from this conversation: a request to visualize two halves of a BOLLI AI-literacy session — the Foundations lecture and the live Writing Coach demo — sharpened, cycle by cycle, into a complete build instruction.

✦ What's working

  • "How these two parts are related" reaches for synthesis, not just a recap of two topics.
  • "How the attendees responded" asks for reception, not just content — a more alive request than a standard summary.

→ What's still missing

  • No stated relationship — "related" is a question, not an answer.
  • No destination: who is this visualization actually for?
  • No success criterion: nothing defines what the finished piece needs to demonstrate.

→ What's still missing

  • "Include specific member comments" is still a directive, not a selection — risk of generic, easiest-to-find quotes.
  • Destination still unstated: portal slot, Grand Learning View, or something else?

✦ What's working

  • Naming the three people directly removes the AI's guesswork entirely — it will pull the exact moments that show assimilation, not just any comment.
  • This took the prior round's suggestion further than the suggestion itself: a technique ("name specific people") became an instance (these three people).

→ What's still missing

  • Which moment each person should illustrate is still implicit — workable, but one layer short of fully locked in.
  • Destination/audience for the finished artifact: still never stated.
↓ + what next version adds

A literal build instruction — and a constraint on how it should be built

4

Version 4 — The Build Instruction

A narrative review becomes a deliverable, with an explicit implementation constraint.

✓ Subject ✓ Identity ✓ Purpose ✗ Audience ✓ Success Criterion ✓ Intellectual Frame
I want visualize two major parts of the Zoom transcript - The learning session in the Foundations - Meaning of Words,Generative,and RAG - The use of the prompt narrative coach to create a comprehensive prompt How these two parts are related How the attendees responded to this learning Describe how the foundation concepts are the theory put into practice of the writing coach - how it works The key point is that the writing coach process uses Claude to assess the current state of the prompt and improve it Include specific members (Mark Lewis,Dennis McCarthy,Hal Shear) comments to illustrate how the writing coach is being perceived and assimilated by the attendees The purpose is help the attendees to engage in the writing coach to create their own narratives and the results and prompt evolution Please create an HTML file artifact that visualizes your response to this narrative — don't create any API calls in the artifact.

✦ What's working

  • "create an HTML file artifact" converts a narrative review into an actual build instruction — no more interpretation needed about the deliverable's form.
  • "don't create any API calls" removes implementation ambiguity outright, before any code gets written.

→ What's still missing

  • Audience/destination — who the finished artifact actually serves — was never pinned down across all four versions. Format is now fully specified; the reader for that format is not.

Key Lesson

A prompt isn't complete because it's long — it's complete when each dimension shaping the response has been named. Subject was solid from the first draft, but Identity, Purpose, Success Criterion, and Intellectual Frame each only arrived once stated outright: theory-into-practice as the throughline, Claude's assessment role as the mechanism, real names instead of "members," and a literal build instruction instead of a request. The one dimension that never resolved — Audience, who the finished artifact actually serves — is the most human of the six, because it asks not what you want, but who you're making it for. A complete prompt narrows what a model has to search; specificity still has to come from the person writing, one cycle at a time.
