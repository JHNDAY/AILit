✨ Game Changer for Non-Technical Users! Instead of requiring volunteers to install Python and use Terminal/Command Prompt, they can simply upload data, click a button, and get results. Completely browser-based.

Why Run Python in the Browser?

This approach eliminates nearly all the complexity for non-technical users:

  • Zero Installation: No Python to install, no pip, no Terminal
  • One Click Processing: Upload → Click Run → Download Results
  • Cross-Platform: Works on Mac, Windows, Linux, iPad, even phones
  • Data Privacy: Everything runs locally on the user's computer
  • Instant Results: No setup delay, immediate feedback
  • Beautiful Interface: Professional web interface instead of Terminal windows

Comparison: Different Approaches

🐍 PyScript (Recommended)

Python runs directly in the browser using Pyodide (Python compiled to WebAssembly).

✓ Advantages

  • Pure Python code—minimal changes needed
  • Popular libraries work: pandas, numpy, matplotlib
  • No server required
  • Data stays on user's computer
  • Simple integration into HTML
  • Growing ecosystem

✗ Limitations

  • Some libraries not supported yet
  • First load takes 10-15 seconds
  • Performance slower than native Python
  • Limited file system access
  • Some packages require compilation
Use Case: Perfect for data processing scripts (pandas), calculations, data transformations. Great for your CSV processing use case!
Code to Add:
<script defer src="https://pyscript.net/latest/pyscript.js"></script> <link rel="stylesheet" href="https://pyscript.net/latest/pyscript.css" /> <py-script> import pandas as pd def process_data(csv_content): df = pd.read_csv(csv_content) # Your processing logic here return df </py-script>

☁️ Server-Based (Flask/FastAPI)

Run Python on a backend server, with a web interface for upload/download.

✓ Advantages

  • Full Python functionality
  • All libraries supported
  • Maximum performance
  • Database storage possible
  • User accounts & history
  • Scheduled processing

✗ Limitations

  • Requires server hosting
  • Monthly costs ($5-50+)
  • More complex setup
  • Data sent to server
  • Server must stay running
  • More maintenance required
Privacy Note: User data is sent to your server and processed there. You need privacy policies and GDPR compliance.
Platforms to Use:
  • Heroku — Easy deployment, free tier available
  • PythonAnywhere — Made for Python, beginner-friendly
  • Replit — Quick prototyping, easy sharing
  • DigitalOcean — Full control, professional

📓 JupyterLite (Advanced)

Full Jupyter notebook environment running in the browser (Pyodide-based).

✓ Advantages

  • Notebook interface (familiar)
  • Step-by-step execution
  • Educational value
  • Output visualization
  • No server needed

✗ Limitations

  • Learning curve for non-technical
  • Same PyScript limitations
  • More complex interface
  • More setup required
  • Overkill for simple tasks
Use Case: Better for teaching/learning, showing step-by-step analysis. Less ideal for simple one-button "run script" tasks.

⚡ Streamlit (Modern Alternative)

Rapidly build data apps with minimal code. Runs on a server but much simpler than Flask.

✓ Advantages

  • Minimal code needed
  • Beautiful UI auto-generated
  • Full Python support
  • Easy to deploy
  • Interactive widgets

✗ Limitations

  • Requires server hosting
  • Data sent to server
  • Costs money to host
  • Slower cold starts
  • Not as customizable
Quick Example:
import streamlit as st import pandas as pd uploaded_file = st.file_uploader("Upload CSV") if uploaded_file: df = pd.read_csv(uploaded_file) st.dataframe(df) # Your processing here

🎯 Our Recommendation for BOLLI Volunteers

Use PyScript for most projects. Here's why:

  • Zero cost: Free forever
  • No server maintenance: Host on GitHub Pages
  • Perfect for volunteers: No installation at all
  • Ideal for data processing: pandas and numpy work great
  • Excellent privacy: All processing stays on user's computer
  • Easy to customize: Just modify the Python code in the HTML

When to use alternatives:

  • Server-based: If you need advanced libraries (machine learning models) or want to store results
  • Streamlit: If you want the beautiful UI without coding HTML
  • JupyterLite: If you want to teach the process, not just show results

Implementation Guide: PyScript Example

1. Create an HTML Page

Start with the example provided: python-web-runner.html

2. Customize the Python Code

Inside the <py-script> section, replace the processing logic:

def process_csv(csv_content): import pandas as pd df = pd.read_csv(io.StringIO(csv_content)) # YOUR CUSTOM PROCESSING HERE df['new_column'] = df['existing_column'] * 2 return df.to_csv(index=False)

3. Host on GitHub Pages

  1. Upload the HTML file to your repository
  2. Access it via: https://yourgithub.com/filename.html
  3. Share the link with volunteers

4. Test It

  1. Create a sample CSV file with your expected data format
  2. Upload it to your web interface
  3. Click Run and check the results
  4. Debug any Python errors (they'll show in the output log)
