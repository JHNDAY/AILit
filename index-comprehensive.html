Welcome!

We offer two completely different approaches to running Python scripts:

Option 1: Web-Based (Easiest): Upload your data to a website, click a button, download results. Perfect for non-technical volunteers who just want results without any setup.

Option 2: Local Installation (More Control): Install Python on your computer and run scripts using Terminal/Command Prompt. Better if you want to understand how Python works or need advanced features.

We recommend starting with the web-based approach for most volunteers. Switch to local installation only if needed.

Frequently Asked Questions

➤ What's the difference between these approaches?
Web-Based: Upload data → Click "Run" → Download results. Everything happens in your browser. No installation, no Terminal, no technical knowledge needed.

Local Installation: Install Python on your computer → Use Terminal/Command Prompt → Run scripts manually. More control, but requires technical setup.
➤ Which should I recommend to volunteers?
Start with web-based. It's dramatically simpler — volunteers just open a website, upload their data, click a button, and get results. No installation headaches, no Terminal windows, no confusing error messages. If they need more advanced features later, they can learn local installation.
➤ Is the web-based approach limited?
Not at all. It supports pandas, numpy, and most data processing tasks. You can process CSV files, calculate statistics, transform data, and much more. It's only limited if you need specialized libraries (like TensorFlow for deep learning). But for most CSV processing and data analysis, it's perfect.
➤ How do I customize the web runner for my specific scripts?
Edit the Python code in the HTML file. Look for the `` section and replace the example processing code with your own. Your Python logic stays the same — we just provide the upload/download interface. The Instructor Resources page has examples.
➤ Is web-based secure? Does data get sent to servers?
Yes, it's secure. The web-based runner (PyScript) processes everything on the volunteer's own computer. No data is sent to any server. It all stays on their device.
➤ Which approach is free?
Both are completely free. Local Python installation is free (Python is open-source). Web-based hosting is free (GitHub Pages). No costs either way.
➤ Can I use both approaches for different projects?
Absolutely. Use web-based for simple data processing tasks (perfect for volunteers). Use local installation when you need more advanced features or want to teach Python. Each has its place.
